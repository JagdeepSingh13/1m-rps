1. autocannon to simulate large number of requests
2. autocannon -m GET --connections 20 --duration 20 --pipelining 2 --workers 6 "http://localhost:3001/simple"
    -w for number of threads
    -p for number of requests one after another
    -c number of connections we want to make to the server
    c * p gives num requests handled concurrently by the server
